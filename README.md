# The Chrono-Relic Vault — Personal Portfolio

An interactive, puzzle-driven developer portfolio built around five chambers designed to reveal my skills, projects, education, and story.

🔗 **Live Demo:** https://sarveshj-dev.vercel.app

## ✨ Features
- **Interactive Chamber Progression:** Solve timed mini-challenges to unlock sections of the portfolio.
- **Custom Theme & UI:** Designed with a dark, relic-vault aesthetic and responsive layout.
- **Fast Static Hosting:** Deployed via Vercel with automatic SSL.
